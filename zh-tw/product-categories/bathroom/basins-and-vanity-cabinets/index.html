面盆、檯面與整體浴櫃
#

面盆與洗手台櫃是育宏國際衛浴業務的核心。產品涵蓋可與檯面無縫黏合的壓克力實心面盆、膠殼人造石檯面、實心人造石檯面、陶瓷一體盆組、薄邊盆，以及板岩紋檯面。

多數產品可訂製，檯面尺寸與形式可客製，育宏可將面盆、檯面、櫃體與鏡櫃整體規劃。

官網分類頁：面盆與洗手台櫃

壓克力實心面盆
#

育宏的100%MMA壓克力實心面盆設計可與人造石檯面無縫黏合，檯面尺寸與形式可客製。

  • U-101 — 圓形面盆；檯面尺寸與形式可客製；100%MMA人造石壓克力實心。
  • U-102 — 下嵌式衛浴面盆；檯面可客製。
  • U-103 — 下嵌式面盆；檯面可客製。
  • U-105 — 矩形下嵌式面盆；檯面可客製。

材質特性為耐黃變、耐燃、耐熱衝擊、耐化學品、耐刮、抗污垢，表面無毛細孔、不吸收物質。與複合壓克力及聚酯樹脂水槽的詳細比較，請見廚房水槽材質說明。

膠殼人造石檯面
#

膠殼人造石檯面以不飽和聚酯樹脂與碳酸鈣灌注成型，表面上膠衣呈現亮麗光澤。常見於公共空間與公寓建案，造型包含圓弧型、斜型、方形、P型、D型、小圓弧型與小方形。

  • 圓弧型
  • 斜型
  • 方形
  • P型
  • D型
  • 小圓弧型
  • 小方形

此類檯面在實用性與成本之間取得平衡，並提供多種顏色。

實心人造石檯面
#

  • 實心人造石檯面 — 以不飽和聚酯樹脂混合純氫氧化鋁粉灌注成型。官網說明表面細膩、耐水與耐化學性佳、質地絲滑，適合無接縫接合，可搭配100%MMA水槽或多種安裝方式。

陶瓷盆組
#

陶瓷盆組將一體成型陶瓷盆與全櫃體烤漆的PVC發泡板浴櫃、鏡櫃搭配。櫃體設計可承載陶瓷盆重量。型號：

  • 3660
  • 4050
  • 4660
  • 4760
  • 4860

陶瓷材質硬度高、易清潔、不易藏菌，並提供多種造型與尺寸。

薄邊盆
#

薄邊盆將消光人造石檯面與面盆一體成型，搭配PVC發泡板浴櫃。檯面特性為耐用、硬度高、耐熱、耐磨、易清潔、不吸水。門片為無把手設計，標準白色，其他顏色可訂製。

  • 5048 — 檯面寬50公分、深48公分。
  • 6048 — 檯面寬60公分、深48公分。
  • 7048 — 檯面寬70公分、深48公分。
  • 8048 — 檯面寬80公分、深48公分。
  • 9048 — 檯面寬90公分、深48公分。
  • 10048 — 檯面寬100公分、深48公分。
  • 12048 — 檯面寬120公分、深48公分。
  • 15048 — 檯面寬150公分、深48公分。

板岩紋檯面
#

板岩紋檯面採用仿天然板岩紋理的啞光人造石，厚邊設計增加視覺份量。櫃體結構與門片選項與薄邊盆系列相同。

  • 6050 — 檯面寬60公分、深50公分。
  • 7050 — 檯面寬70公分、深50公分。
  • 8050 — 檯面寬80公分、深50公分。
  • 9050 — 檯面寬90公分、深50公分。
  • 10050 — 檯面寬100公分、深50公分。
  • 12050 — 檯面寬120公分、深50公分。

選購建議
#

  • 希望面盆與檯面接縫最少： 可考慮壓克力實心面盆搭配無縫檯面。
  • 工程案需要控制預算： 可比較膠殼人造石檯面。
  • 想要細膩的實心人造石質感： 可考慮實心人造石檯面搭配壓克力面盆。
  • 需要含收納的完整單元： 可比較陶瓷盆組、薄邊盆浴櫃與板岩紋浴櫃。

住宅詢問請提供可用寬度、偏好的面盆造型與收納需求；設計或工程案請附圖面與預估數量，以便育宏確認合適型號與價格。
