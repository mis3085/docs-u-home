人造石面盆、洗手盆、洗手台訂製就找【YU HOME 育宏國際】

台灣設計製造的壓克力實心人造石衛浴產品
#

育宏國際有限公司是台灣衛浴品牌，專精於設計及生產衛浴面盆、檯面臉盆、洗手盆、浴室櫃類、廚房水槽、洗衣檯等配件。公司初期以雅松石之名成立於1993年，並於2003年更名為育宏國際有限公司，整合研發、生產與品牌經營。

材質從早期膠殼人造石、實心人造石，發展到100%MMA壓克力實心人造石。所有產品皆可依照客戶需求訂製，官網並強調以台灣設計製造的品牌行銷全世界。

公司概況
#

  • 創立： 1993年，初期以雅松石之名成立；2003年更名為育宏國際有限公司
  • 總公司與廠區： 雲林縣斗六市斗工12路52號
  • 核心業務： 衛浴面盆、檯面臉盆、洗手盆、浴室櫃類、廚房水槽、洗衣檯及相關配件的設計與製造
  • 主要材質： 100%MMA壓克力實心人造石，另有實心人造石、膠殼人造石、陶瓷、消光人造石與板岩紋人造石
  • 認證： 100%MMA壓克力實心水槽通過美國國家標準ANSI Z124.6；官網公開SGS試驗報告與CNS試驗結果
  • 製造角色： 為國際衛浴品牌代工生產；公司簡介提到獲得日本東陶TOTO台灣廠肯定，代理生產製造
  • 市場： 台灣設計製造，行銷全世界

產品系列
#

育宏的產品依照使用場域分類，涵蓋衛浴、陽台與洗衣、廚房、無障礙空間，以及五金周邊與工程建材。

  • 衛浴專區 — 人造石檯面、浴室鏡箱、鏡櫃、PVC防水吊櫃、面盆與浴櫃。包含14款浴室鏡櫃、2款浴室吊櫃，以及壓克力實心面盆、膠殼人造石檯面、實心人造石檯面、陶瓷盆組、薄邊盆與板岩紋檯面。 瀏覽衛浴產品
  • 陽台與洗衣專區 — 一體式洗衣台，提供固定式或活動式洗衣板、不鏽鋼腳架、PVC發泡板櫃體，以及搭配的洗衣台吊櫃。 瀏覽陽台與洗衣產品
  • 廚房專區 — 100%MMA壓克力實心廚房水槽，提供單槽與雙槽配置，檯面尺寸可客製，水槽與檯面可無縫黏合。 瀏覽廚房產品
  • 無障礙專區 — 無障礙洗手台，前方內縮並保留輪椅使用空間，尺寸、面盆位置與高度可客製。 瀏覽無障礙產品
  • 五金周邊與工程建材 — 不鏽鋼壁掛式與立式水龍頭、人造石門檻、實心複合輕質門檻、擋水條與樓梯擋塊。 瀏覽五金與工程建材
  • 材質介紹 — 100%MMA人造石壓克力實心材質、膠殼人造石、實心人造石、陶瓷、薄邊盆消光人造石與板岩紋啞光人造石檯面的特性說明。

應用空間
#

  • 衛浴空間 — 檯面水槽、嵌入式洗手台、壁掛式水槽與一體盆／浴櫃整合，適合客浴、主衛、設計旅店與精品商空。
  • 陽台空間 — 柱腳或鋁腳櫃體洗衣檯、不鏽鋼腳架洗衣檯與洗衣台吊櫃的收納配置。
  • 廚房空間 — 單槽、雙槽與100%壓克力水槽，適合日常烹調、中島與開放式廚房。
  • 無障礙空間 — 輪椅友善檯面、無接縫設計與客製規劃，適用住宅、醫療院所、長照機構與公共建築。

案例與客製服務
#

育宏公開洗手台、洗衣檯與客製化案例，涵蓋私人住宅、學校、餐廳、民宿、公共廁所與商業空間。官網列出的案例包括手作面盆衛浴案例、南投日月潭民宿衛浴規劃、新竹茄苳國小附設幼兒園公共廁所檯面，以及台中、彰化、嘉義、雲林、苗栗、新竹等地的洗衣檯案例。
